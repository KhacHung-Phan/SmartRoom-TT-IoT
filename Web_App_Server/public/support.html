Quickstart

Serve bằng HTTP (khuyên dùng)

Mở terminal tại thư mục dự án, chạy:

python -m http.server 8000

Sau đó mở trình duyệt: http://localhost:8000

Luồng hệ thống
ESP32 ⇄ MQTT ⇄ Bridge ⇄ Firebase

Các bước đề xuất

  • ESP32 publish sensor/telemetry + state + event (alarm)
  • ESP32 subscribe cmd: room1/cmd/light, room1/cmd/fan, room1/cmd/siren, room1/cmd/mode
  • Bridge: MQTT → Firebase (dashboard + log) và Firebase → MQTT (khi web gửi lệnh)
